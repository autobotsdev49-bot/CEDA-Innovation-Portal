CEDA Innovation Portal — Assessor Workspace UI Screens
Conceptual UI (not a description of CEDA's present system)

Desktop (AS-01..AS-13) and mobile (ASM-01..ASM-04) PNGs.
Open individual PNGs for crisp readable screen designs.

Core design commitments:
- Assigned-case access and confidentiality
- Conflict-of-interest declaration
- Six exact assessment categories from challenge materials
- Score each from 1 to 5, with comments; no invented weights
- Secure applicant clarification requests and supplementary evidence
- Assessment submission is NOT final approval or decision release
- All names, scores, counts, application references are fictional mock data

The matching HTML/CSS files are also included as static design references. They are not wired to a backend.
